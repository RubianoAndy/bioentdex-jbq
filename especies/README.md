# Aves observadas en los paisajes sonoros

Las fichas añadidas para tordo llanero, sirirí común, turpial oriental, playero solitario,
capita negra, coquito, alcaraván, pibí del bosque y espiguero negriblanco se basan en las
identificaciones publicadas por [AVE-WIX](https://luciabernal555.wixsite.com/avifaunahumeljab/paisajes-sonoros).
Se incorporan como aves de observación, no como especies capturables. Las ilustraciones SVG son
originales para la aplicación; las fotografías de la página sirvieron solo de inspiración.

La fuente reporta identificaciones en grabaciones y transectos; esto no afirma que cada especie
sea residente permanente ni estima su abundancia. Las fichas usan el estado `NE` como valor
pendiente de verificación para el contexto local, no como evaluación global de amenaza.
La mención de “Parkesia” no se añade como especie porque la página no identifica el epíteto
específico.

Familias y órdenes se contrastaron con el servicio taxonómico de
[GBIF](https://api.gbif.org/v1/species/match). El nombre “Quicalus” de la página se normalizó a
`Quiscalus`, de acuerdo con el nombre aceptado.
